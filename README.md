# Futbol Analiz PRO V8

Mobil Streamlit futbol analiz uygulaması.

## V8 yeniliği
- Seçilen günün fikstürünü tarar.
- Kota dostu şekilde sınırlı sayıda maç için API-Football tahminlerini derinleştirir.
- Model yüzdesine göre en güçlü 4 adayı çıkarır.
- 4 maç için yeterli güven yoksa bunu zorlamaz; mevcut adayları gösterir.
- Canlı maç analizi, normal maç analizi ve backtest korunmuştur.
