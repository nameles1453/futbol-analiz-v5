# Futbol Analiz PRO V5 Mobil

Tahminler: 1/X/2, ilk yarı 1/X/2, Alt/Üst 1.5/2.5/3.5, KG Var/Yok, en olası skorlar, beklenen gol, oran-model karşılaştırması, form ve walk-forward backtest. Fixture ID ile API-Football oyuncu/sakatlık/ilk 11 kayıt özeti alınabilir.

Kurulum: GitHub'a app.py ve requirements.txt yükle, Streamlit Community Cloud ile deploy et. Secrets: `APIFOOTBALL_KEY = "API_KEYIN"`.

Tahminler istatistiksel model çıktılarıdır; kesin sonuç veya garanti değildir.
